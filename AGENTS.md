# AGENTS.md

## What this repo is

Registry of [Nomad Pack](https://github.com/hashicorp/nomad-pack) packs. Packs are Helm-like: HCL
metadata/variables plus Go templates. There is no application code; the packs are the deliverable.
Each pack lives in `packs/<name>/` with `metadata.hcl`, `variables.hcl`, `templates/*.tpl`,
`outputs.tpl`, `README.md`, `CHANGELOG.md`, and optional `.ci/vars-*.hcl`.
`examples/<pack>-<scenario>/variables.hcl` hold sample deployments used by the Go tests and docs.

## Setup

Toolchain is pinned in `mise.toml` (go 1.25, nomad 2, nomad-pack 0.4.2, hcl2json, terraform-docs,
git-cliff, shellcheck, bump-my-version). Run `mise install`. The docs hook also needs `jq` on
`PATH`.

## Commands

- `mise run pre-commit` — full lint/format/docs gate (`pre-commit run --all-files`). Run before
  committing.
- `mise run fmt` — `nomad fmt -recursive .`.
- `mise run test` — Go tests from `test/`; requires a **live Nomad cluster** and `nomad-pack` in
  `PATH`. Single test: `cd test && go test -run TestCronjobStandard -v`.
- `./scripts/validate-packs.sh packs/<name>` — renders the pack with its `.ci`/`test` var files,
  then `nomad fmt` + `nomad validate` each rendered job (what CI does for changed packs).
- `mise run update-changelogs [-- --commit]` — regenerate every `packs/*/CHANGELOG.md` from git.
- `mise run bump-version` — git-cliff picks the next version; bump-my-version updates `VERSION`,
  every `packs/*/metadata.hcl`, and changelogs, then commits and tags.
- `mise run git-push` — `git push --follow-tags origin HEAD`.

## Generated files — do not hand-edit

- Pack `README.md` content between `<!-- BEGIN_PACK_METADATA -->`/`END` and
  `<!-- BEGIN_TF_DOCS -->`/`END` is generated by the `nomad-pack-docs` pre-commit hook
  (`scripts/nomad-pack-docs.sh`) from `metadata.hcl`/`variables.hcl`. Edit those and run
  `mise run pre-commit`.
- `VERSION` and every `packs/*/metadata.hcl` `pack.version` must stay in sync; change them only via
  `mise run bump-version`.
- `packs/*/CHANGELOG.md` are git-cliff output; regenerate, don't hand-write.

## Conventions and gotchas

- Pack templates use `[[ ... ]]` delimiters, not `{{ ... }}`; `{{ }}` is reserved for Nomad's own
  runtime interpolation. `templates/_helpers.tpl` holds shared `define` blocks.
- Conventional commits are required: `cliff.toml` parses them for changelogs and version bumps.
  Recognized types are feat, fix, refactor, docs, perf, style, test, chore, ci, revert; use `!` for
  breaking changes. Other messages are dropped from changelogs.
- `rendered/` (produced by `validate-packs.sh`) is gitignored build output.
- Only `test/` is a Go module; there is no root `go.mod`, so run Go commands from `test/`.
- Known stale test: `test/webapp_standard_test.go` points at `../examples/webapp-standard`, which
  does not exist (no example named `webapp-standard`). Only `TestCronjobStandard` has a matching
  example today.
